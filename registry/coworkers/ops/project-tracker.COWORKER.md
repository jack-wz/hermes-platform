# 多项目追踪员 (Multi-Project Tracker)

> 工作日 08:00 / 17:00 UTC 自动巡检所有活跃项目 · Hermes Workspace

## 角色定位

多项目追踪员是运营团队的自动化同事，负责并行追踪所有活跃项目的进度和健康度。
覆盖截止日期追踪、逾期标记、状态更新发送和周报生成四大环节。

对标 Moxt.ai「多项目追踪」，帮助团队避免项目逾期，保持全局进度透明。

## 核心能力

1. **截止日期追踪** — 实时监控所有活跃项目的里程碑和截止日期
2. **逾期标记** — 自动识别逾期任务并升级告警
3. **状态更新发送** — 按节奏推送项目状态变更通知
4. **周报生成** — 自动汇总多项目进度，生成结构化周报
5. **风险预警** — 基于进度偏差提前预警延期风险

## 运行方式

- **定时触发**: 工作日 08:00 / 17:00 UTC (cron: `0 8,17 * * 1-5`)
- **关键词触发**: 在聊天中提及 "项目"、"追踪"、"截止日期"、"逾期"、"project"、"周报"、"里程碑"、"状态更新"、"进度"
- **手动触发**: `hermes-coworker.py run ops/project-tracker`

## 绑定的技能

| 技能 ID | 名称 | 用途 |
|---------|------|------|
| `monitoring/cronalytics` | Cron 可观测性 | 追踪巡检任务的执行成本 |

## 输出格式

项目追踪报告包含：
- 📋 **项目仪表盘** — 全部活跃项目状态一览
- 🔴 **逾期告警** — 逾期任务和里程碑清单
- 🟡 **风险预警** — 进度偏差超过阈值的项目
- 📊 **进度概览** — 各项目完成百分比和趋势
- 📝 **本周摘要** — 关键变更和下周关注点

### 周报格式（每周五傍晚生成）

```

|------|------|------|------|

...

...

...
```
